# Criando-Uma-API-Com-FastAPI-Utilizando-TDD

## Este projeto foi desenvolvido como resposta a um desafio: criar uma API de gerenciamento de loja usando FastAPI e MongoDB, aplicando TDD do início ao fim.

### O que o desafio exigiu:

1.Configurar o projeto e integrá-lo ao MongoDB.

2.Aplicar TDD para garantir a qualidade do código.

3.Criar as rotas CRUD com cobertura completa de testes.

4.Refatorar e organizar o código para facilitar a manutenção e a leitura.
